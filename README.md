# Assignment 2 – Conceptual Database Design

This repository contains my conceptual database design for a **Student Habits and Academic Performance** system.

The design models how student information is related to study habits, lifestyle factors, and academic performance.

## Entities

The conceptual design includes four entities:

* `STUDENT`
* `STUDY_HABIT`
* `LIFESTYLE`
* `ACADEMIC_PERFORMANCE`

Each entity includes its main attributes and two sample data records. The entities are connected using relationship lines to show how the data is related.
